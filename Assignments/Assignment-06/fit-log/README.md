
# 💪 FITLOG - Workout Library & Fitness Tracker

**FITLOG** is a modern workout library and fitness tracking application designed to help users organize their fitness routines, manage daily workout plans, and track their progress. It provides a simple and user-friendly interface to make workout management easier and more effective.

## 🚀 Technologies Used

- **Next.js** - React framework for building the application.
- **React** - Component-based UI development.
- **TypeScript** - Type safety and better code quality.
- **Tailwind CSS** - Responsive and modern UI styling.
- **DaisyUI** - Prebuilt UI components.
- **React Icons / Lucide React** - Icons and visual elements.
- **React Toastify** - Notifications and toast messages.

## ✨ Key Features

### 1. 🏋️ Workout Library
Browse a collection of exercises with detailed information, including equipment, difficulty, duration, calories burned, and muscle groups.

### 2. 📋 Daily Workout Plan
Add exercises to a daily workout plan and organize your fitness routine in one place.

### 3. ⭐ Save Favorite Workouts
Save favorite exercises for quick access whenever you need them.

### 4. 📊 Workout Statistics
View workout summaries, including total exercises, workout duration, and estimated calories burned.

### 5. 📱 Fully Responsive Design
Enjoy a clean and modern user interface optimized for mobile, tablet, and desktop devices.

## 📂 Project Overview

FITLOG helps users build consistent workout habits by combining an organized exercise library, daily planning, saved workouts, and useful fitness statistics in one application.

## 🎯 Project Goal

The goal of FITLOG is to make workout planning simple, accessible, and organized while encouraging users to stay consistent with their fitness journey.
